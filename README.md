# 코드 미리보기 (code-preview.html)

비개발자 학습자가 HTML / CSS / JavaScript 코드를 붙여넣으면 즉시 결과 화면을 확인할 수 있는
**단일 HTML 파일** 도구입니다. 강의·칼럼의 예제 코드를 그 자리에서 실행해 보는 용도로 만들었습니다.

빌드 도구·npm·프레임워크·외부 CDN을 **도구 자체에는 전혀 쓰지 않습니다.**
파일을 더블클릭해 브라우저로 열면(`file://`) 인터넷 없이도 그대로 동작합니다.

- ▶ **도구 실행**: https://frontierall.github.io/CodeBom-2608/
- 📖 **사용법 문서**: https://frontierall.github.io/CodeBom-2608/guide.html

| 버튼 | 설명 |
|---|---|

| 자동 실행 | 켜 두면 타이핑을 멈춘 뒤 0.5초 후 자동으로 다시 실행합니다 |

| ✨ 정렬 | 태그 깊이에 맞춰 들여쓰기를 정리합니다 (`Ctrl+Z`로 되돌리기) |

| 📋 코드 복사 | 입력한 코드를 클립보드에 복사합니다 |

미리보기 쪽에는 **디바이스 폭 원클릭 전환**(🖥️ 데스크톱 100% / 💻 태블릿 768px / 📱 모바일 375px),
**🔄 새로고침**(코드는 그대로 두고 화면만 다시 불러오기), **⛶ 전체화면**(`Esc`로 빠져나오기)이 있습니다.

### 편집 탭

에디터 위에 **📄 통합 문서 / HTML / CSS / JS** 탭이 있습니다.

- **통합 문서**(기본)는 예제를 통째로 복사·붙여넣기 하는 자리입니다.
- **HTML / CSS / JS** 탭은 각각 `<body>` · `<style>` · `<script>` **안쪽만 잘라서 보여주는 창**입니다.
  자료가 세 덩어리로 나뉘어 있을 때 각 탭에 나눠 붙여넣으면 됩니다.
- 해당 부분이 아직 없으면 만들지 물어본 뒤 빈 `<style>` / `<script>`를 넣어줍니다.
- 실행·저장·복사·다운로드는 **언제나 통합 문서 기준**입니다. 탭은 보기 방식일 뿐이라
  파일이 세 개로 쪼개지지 않습니다.
- **부분 탭에서도 줄 번호는 통합 문서 기준으로 표시됩니다.** CSS 탭이 4번째 줄에서 시작하면
  줄 번호도 4부터 시작하므로, 콘솔의 `[6번째 줄]` 오류 표시와 눈으로 바로 맞출 수 있습니다.

- 에디터에 **줄 번호**와 **구문 강조**가 표시되고(탭에 따라 HTML/CSS/JS 규칙이 바뀝니다),
  우측 상단에 `1,807 자 / 41 줄`이 나옵니다.
- 좌우 분할선을 드래그하면 폭이 조절되고, 더블클릭하면 반반으로 돌아갑니다.
- 화면 폭이 768px 이하가 되면 위아래 배치로 바뀝니다.
- 입력한 코드는 localStorage에 자동 저장되어 다시 열면 복원됩니다.

## 동작 방식 메모

### 보안 · 격리
- 실행 결과는 `iframe.srcdoc` 에 주입하며, iframe에는 **`allow-same-origin` 을 주지 않습니다.**
  `allow-scripts` 와 `allow-same-origin` 을 함께 주면 sandbox가 무력화되어 미리보기 코드가
  도구 페이지와 localStorage를 조작할 수 있게 됩니다. 실제 sandbox 값은
  `allow-scripts allow-modals allow-forms allow-popups` 입니다.
- `allow-modals` 는 `alert / confirm / prompt` 예제를 위해 필요합니다. 이 값이 없으면 브라우저가
  다이얼로그를 **조용히 무시**합니다(측정값: 있을 때 21,158ms 대기 / 없을 때 0.1ms 무시).
  `allow-modals` 는 부모 창 접근 권한과 무관합니다.
- localStorage는 sandbox iframe 안에서 차단되므로 **부모 창에서만** 사용합니다.
  (그래서 내장 '할 일 목록' 예제도 저장 기능을 쓰지 않습니다.)

### 콘솔 · 줄 번호
- 주입 코드 맨 앞에 후킹 스크립트를 덧붙여 `console.log/info/warn/error`,
  `window.onerror`, `unhandledrejection`, 리소스 로드 실패를 가로채
  `parent.postMessage` 로 부모에 전달합니다.
- 후킹 스크립트는 **줄바꿈이 하나도 없는 한 줄**로 압축해 넣기 때문에
  **오류 줄 번호가 입력한 코드의 줄 번호와 정확히 일치합니다.**
- 값은 iframe 안에서 먼저 문자열로 직렬화합니다. `postMessage` 로 DOM 객체를 그대로 보내면
  구조화 복제에 실패해 로그가 조용히 사라지기 때문입니다.

### 에디터
- 투명한 `textarea` 아래에 `<pre>` 강조 레이어를 겹쳐 구문 강조를 구현했습니다.
  두 층의 글꼴·줄 높이·여백을 동일하게 맞추고, 스크롤을 동기화합니다.
- `textarea` 에만 스크롤바가 생겨 스크롤 범위가 어긋나므로, 강조 레이어에 스크롤바 폭만큼
  여백을 더해 양쪽 끝에서도 글자가 어긋나지 않게 했습니다.
- **한글 입력(IME) 조합 중에는** 강조 레이어를 감추고 글자를 직접 보여줍니다.
  투명 글자 상태로 두면 조합 중인 글자가 보이지 않기 때문입니다.

### 라이브러리 삽입
- 📚 버튼을 누르면 팝업이 열리고, Tailwind CSS · Font Awesome · jQuery 3.7 · Three.js ·
  Chart.js · 한글 웹폰트(Noto Sans KR) 를 체크로 켜고 끌 수 있습니다.
- 프리뷰에만 몰래 주입하지 않고 **내 코드의 `<head>` 안에 태그를 직접 넣습니다.**
  체크를 풀면 그 줄이 지워집니다. 보이는 코드 = 실행되는 코드 = 저장되는 파일이 일치해야
  💾 저장한 파일을 따로 열어도 똑같이 보이고, 수강생이 코드를 다른 곳에 복사해도 깨지지 않습니다.
- CDN은 인터넷 연결이 필요하므로 팝업에 연결 상태 배지를 띄우고,
  로드에 실패하면 콘솔에 한글로 안내합니다. **내장 예제 8개는 모두 CDN 없이 동작합니다.**

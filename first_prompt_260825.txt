# 프로젝트: HTML/JS 코드 미리보기 도구 만들기

## 목표
비개발자 학습자가 HTML/CSS/JavaScript 코드를 붙여넣으면
즉시 웹 화면으로 확인할 수 있는 웹 도구를 만든다.
강의·칼럼에서 예제 코드를 직접 실행해보게 하는 용도다.

## 기술 제약 (반드시 지킬 것)
- **단일 HTML 파일 1개**로 완성한다. 파일명: `code-preview.html`
- 빌드 도구, npm, 프레임워크, 외부 CDN 라이브러리 일절 사용 금지
- 순수 HTML + CSS + Vanilla JavaScript만 사용
- 파일을 더블클릭해 브라우저로 열었을 때(file:// 프로토콜) 정상 동작해야 한다
- 인터넷 연결 없이도 동작해야 한다

## 화면 레이아웃
┌────────────────┬────────────────┐
│  코드 입력창    │   미리보기      │
│  (textarea)    │   (iframe)     │
├────────────────┴────────────────┤
│  콘솔 출력 영역                  │
└─────────────────────────────────┘

- 상단에 툴바(버튼들), 그 아래 좌우 2분할, 하단에 콘솔
- 좌우 분할선을 마우스로 드래그해 폭 조절 가능
- 화면 폭 768px 이하에서는 위아래 배치로 전환
- 콘솔 영역은 접기/펼치기 가능

## 핵심 기능

### 1. 코드 입력
- textarea **한 칸**만 사용한다. HTML/CSS/JS를 나누지 말 것.
  (이유: 예제 코드를 통째로 복사·붙여넣기 할 수 있어야 함)
- 고정폭 글꼴, Tab 키를 누르면 포커스 이동이 아니라 들여쓰기가 입력되도록 처리
- 처음 열었을 때 간단한 샘플 코드가 미리 들어가 있게 한다

### 2. 실행 / 렌더링
- `▶ 실행` 버튼 클릭 시 코드를 `iframe.srcdoc`에 주입해 렌더
- `자동 실행` 체크박스: 켜져 있으면 타이핑이 멈춘 뒤 500ms 디바운스로 자동 갱신
- Ctrl+Enter(Mac은 Cmd+Enter) 단축키로도 실행
- **보안**: iframe에 `sandbox="allow-scripts"` 만 부여한다.
  `allow-same-origin`은 절대 함께 넣지 말 것 (부모 페이지 조작 위험)

### 3. 콘솔 출력 (중요)
sandbox iframe 내부의 출력을 부모 창에서 볼 수 있어야 한다.
- iframe에 주입되는 코드 **맨 앞에** 후킹 스크립트를 자동으로 덧붙인다
- `console.log / warn / error`를 가로채 `parent.postMessage`로 전달
- `window.onerror`와 `unhandledrejection`도 잡아서 전달
- 부모는 `message` 이벤트로 받아 콘솔 영역에 출력
- 에러는 빨간색, 경고는 노란색, 일반 로그는 기본색으로 구분
- 에러 발생 시 줄 번호도 함께 표시
- 실행할 때마다 콘솔은 초기화

### 4. 툴바 버튼
- ▶ 실행
- 🔄 초기화 (확인 창을 띄운 뒤 샘플 코드로 되돌림)
- 📋 코드 복사 (클립보드 복사 후 "복사됨!" 토스트 표시)
- 💾 HTML 저장 (입력한 코드를 .html 파일로 다운로드)
- 🪟 새 탭에서 보기 (미리보기만 전체 화면으로)
- 📱 미리보기 폭 전환: 전체 / 모바일(375px) 토글

### 5. 자동 저장
- 입력한 코드를 localStorage에 자동 저장
- 페이지를 다시 열면 마지막 코드를 복원
- **주의**: localStorage는 반드시 부모 창에서만 사용한다
  (sandbox iframe 내부에서는 접근이 차단됨)

## 디자인
- 대상이 비개발자 왕초보다. 깔끔하고 부담 없는 밝은 톤으로.
- 버튼에는 이모지 아이콘 + 한글 라벨을 함께 표기
- 각 영역에 "코드를 입력하세요", "실행 결과", "콘솔" 같은 한글 제목 표시
- 툴바 아래에 한 줄 안내문 배치:
  "코드를 붙여넣고 ▶ 실행을 누르면 오른쪽에 결과가 나타납니다"

## 완료 후
파일을 만든 뒤, 아래 시나리오로 직접 검증한 결과를 알려줄 것:
1. `<button onclick="alert('안녕')">눌러보기</button>` → 클릭 시 alert 동작
2. `<script>console.log('테스트')</script>` → 콘솔 영역에 출력됨
3. 일부러 문법 오류가 있는 코드 → 콘솔에 빨간 에러 메시지 표시
4. 새로고침 후 마지막 코드가 복원됨

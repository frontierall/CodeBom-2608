1. 1분 만에 시작하기 ↑ 위로

  1. 도구를 엽니다. code-preview.html 파일을 더블클릭하거나 위의 ▶ 도구 열기 를 누릅니다.
  2. 코드를 붙여넣습니다. 왼쪽 입력창의 내용을 지우고 예제 코드를 통째로 붙여넣으세요. HTML·CSS·JavaScript를 나눌 필요 없이 한 번에 넣으면 됩니다.
  3. ▶ 실행을 누릅니다. 오른쪽에 결과가 나타납니다. Ctrl + Enter 로도 실행됩니다.
처음이라 붙여넣을 코드가 없다면 툴바의 📂 예제 불러오기 에서 8가지 예제 중 하나를 골라 보세요. 모두 인터넷 없이 동작합니다.

4. 편집 탭 ↑ 위로

입력창 위에 📄 통합 문서 · HTML · CSS · JS 네 개의 탭이 있습니다.

탭보여주는 부분
📄 통합 문서전체 HTML 문서 (기본값). 예제를 통째로 붙여넣는 자리입니다.
HTML<body> 안쪽 내용
CSS<style> 안쪽 내용
JS<script> 안쪽 내용

강의 자료가 HTML / CSS / JS 세 덩어리로 나뉘어 있을 때는 각 탭에 나눠서 붙여넣으면 됩니다. 아직 <style> 이나 <script> 가 없는 코드라면, 탭을 눌렀을 때 "새로 만들까요?" 하고 물어본 뒤 빈 자리를 만들어 줍니다.

탭을 나눠도 파일은 하나입니다 실행 · 저장 · 복사 · 다운로드는 언제나 전체 문서 기준입니다. 각 탭은 전체 문서의 한 부분을 잘라서 보여주는 창일 뿐이라, 파일이 세 개로 쪼개지지 않습니다.
부분 탭에서도 줄 번호는 전체 문서 기준입니다 CSS가 전체 문서의 5번째 줄에서 시작하면, CSS 탭의 줄 번호도 5부터 시작합니다. 그래서 콘솔에 [6번째 줄] 오류가 떠도 지금 보는 탭에서 바로 찾을 수 있습니다.

반응형 웹을 가르칠 때 데스크톱 → 태블릿 → 모바일 순서로 눌러 보여주면 @media 규칙이 어떻게 동작하는지 한눈에 보여줄 수 있습니다.

6. 콘솔 읽는 법 ↑ 위로

결과 화면 아래 검은 영역이 콘솔입니다. 코드가 남긴 메시지와 오류가 여기에 나옵니다.

표시뜻
📄console.log() 로 남긴 일반 메시지
⚠️경고 (console.warn), 외부 파일을 못 불러온 경우
⛔오류. 코드가 멈춘 지점입니다. 몇 번째 줄인지 함께 표시됩니다.
✅실행이 끝났다는 알림

예를 들어 이렇게 나옵니다.

⛔ [3번째 줄] Uncaught SyntaxError: Unexpected token ';'
⛔ [6번째 줄] Uncaught ReferenceError: 없는함수 is not defined
  • SyntaxError — 문법이 틀렸습니다. 괄호·따옴표·세미콜론을 확인해 보세요.
  • ReferenceError … is not defined — 그런 이름을 찾을 수 없습니다. 오타이거나, 아직 만들지 않은 함수입니다.

실행할 때마다 콘솔은 비워집니다. 🧹 지우기 로 직접 비울 수도 있고, 제목 줄을 누르면 접었다 펼 수 있습니다. 오류가 나면 접혀 있어도 자동으로 펼쳐집니다.

체크하면 내 코드에 태그가 실제로 들어갑니다 화면 뒤에서 몰래 넣어주는 방식이 아니라, <head> 안에 불러오기 태그 한 줄이 직접 추가됩니다. 체크를 풀면 그 줄이 지워집니다.
덕분에 보이는 코드 = 실행되는 코드 = 저장되는 파일이 항상 같습니다. 💾 저장한 파일을 나중에 따로 열어도 디자인이 그대로 나오고, 코드를 다른 곳에 복사해도 깨지지 않습니다.
이 기능만은 인터넷 연결이 필요합니다 라이브러리 파일은 인터넷에서 받아옵니다. 연결이 없으면 팝업에 오프라인 배지가 뜨고, 실행 시 콘솔에 "외부 파일을 불러오지 못했습니다" 안내가 나옵니다. 내장 예제 8개는 라이브러리 없이 동작하므로, 인터넷이 끊긴 강의실에서도 수업은 그대로 진행됩니다.

10. 자주 묻는 질문 ↑ 위로

Q. 인터넷이 없어도 되나요?

됩니다. code-preview.html 파일 하나만 있으면 되고, 더블클릭해서 열면 그대로 동작합니다. 외부 라이브러리 기능만 인터넷이 필요합니다.

Q. alert() 이 뜨나요?

뜹니다. alert · confirm · prompt 모두 정상 동작하도록 설정해 두었습니다.

Q. localStorage 예제가 동작하지 않아요.

결과 화면은 안전을 위해 격리된 공간에서 실행되는데, 그 안에서는 브라우저가 localStorage 사용을 막습니다. 저장 기능이 필요한 예제는 배열이나 변수로 바꿔서 만들어 주세요. (내장 '할 일 목록' 예제도 그렇게 되어 있습니다.)

참고로 내가 입력한 코드는 도구가 알아서 저장하므로, 창을 닫아도 사라지지 않습니다.

Q. 내 코드가 서버로 전송되나요?

아닙니다. 모든 처리는 내 브라우저 안에서만 일어납니다. 코드가 어디로도 전송되지 않습니다.

Q. 줄이 길어서 오른쪽이 잘려요.

줄 번호를 정확히 맞추기 위해 자동 줄바꿈을 끄고 가로 스크롤을 씁니다. 입력창 아래쪽 가로 막대로 이동하거나, ✨ 정렬 을 눌러 코드를 정리해 보세요.

Q. 만든 결과물을 다른 사람에게 보여주려면?

💾 HTML 저장 으로 my-code.html 을 내려받아 전달하면 됩니다. 받은 사람이 더블클릭만 하면 똑같이 열립니다.

11. 동작 원리와 보안 ↑ 위로

강사·개발자를 위한 설명입니다. 학습자는 읽지 않아도 됩니다.

격리 실행

입력한 코드는 iframe 의 srcdoc 으로 주입되어 실행되며, 샌드박스 값은 다음과 같습니다.

sandbox="allow-scripts allow-modals allow-forms allow-popups"
  • allow-same-origin 은 일부러 넣지 않았습니다. allow-scripts 와 함께 주면 샌드박스가 사실상 무력화되어, 미리보기 안의 코드가 도구 페이지와 저장된 코드를 마음대로 건드릴 수 있게 됩니다.
  • allow-modals 는 alert 예제를 위해 필요합니다. 이 값이 없으면 브라우저가 대화상자를 조용히 무시합니다 (실측: 있을 때 21,158ms 대기 / 없을 때 0.1ms 무시). 부모 창 접근 권한과는 무관합니다.

콘솔과 줄 번호

격리된 공간의 출력을 부모 창에서 보기 위해, 주입 코드 맨 앞에 후킹 스크립트를 덧붙여 console.log/info/warn/error, window.onerror, unhandledrejection, 리소스 로드 실패를 가로채 postMessage 로 전달합니다.

이 후킹 스크립트는 줄바꿈이 하나도 없는 한 줄로 압축해 넣습니다. 그래서 주입해도 사용자 코드의 줄 번호가 밀리지 않고, 오류 줄 번호가 화면에 보이는 줄 번호와 정확히 일치합니다.

에디터

투명한 textarea 아래에 <pre> 강조 레이어를 겹쳐 구문 강조를 구현했습니다. 한글 입력(IME) 조합 중에는 강조 레이어를 감추고 글자를 직접 보여줍니다. 투명한 상태로 두면 조합 중인 글자가 보이지 않기 때문입니다.

만들 때 지킨 제약

  • 빌드 도구·npm·프레임워크·외부 CDN을 도구 자체에는 전혀 쓰지 않음
  • 순수 HTML + CSS + Vanilla JavaScript, 파일 하나
  • file:// 로 열어도, 인터넷이 없어도 동작

# 프로젝트: HTML/JS 코드 미리보기 도구 만들기

## 목표
비개발자 학습자가 HTML/CSS/JavaScript 코드를 붙여넣으면
즉시 웹 화면으로 확인할 수 있는 웹 도구를 만든다.
강의·칼럼에서 예제 코드를 직접 실행해보게 하는 용도다.

## 기술 제약 (반드시 지킬 것)
- **단일 HTML 파일 1개**로 완성한다. 파일명: `code-preview.html`
- 빌드 도구, npm, 프레임워크, 외부 CDN 라이브러리 일절 사용 금지
- 순수 HTML + CSS + Vanilla JavaScript만 사용
- 파일을 더블클릭해 브라우저로 열었을 때(file:// 프로토콜) 정상 동작해야 한다
- 인터넷 연결 없이도 동작해야 한다

## 화면 레이아웃
┌────────────────┬────────────────┐
│  코드 입력창    │   미리보기      │
│  (textarea)    │   (iframe)     │
├────────────────┴────────────────┤
│  콘솔 출력 영역                  │
└─────────────────────────────────┘

- 상단에 툴바(버튼들), 그 아래 좌우 2분할, 하단에 콘솔
- 좌우 분할선을 마우스로 드래그해 폭 조절 가능
- 화면 폭 768px 이하에서는 위아래 배치로 전환
- 콘솔 영역은 접기/펼치기 가능

## 핵심 기능

### 1. 코드 입력
- textarea **한 칸**만 사용한다. HTML/CSS/JS를 나누지 말 것.
  (이유: 예제 코드를 통째로 복사·붙여넣기 할 수 있어야 함)
- 고정폭 글꼴, Tab 키를 누르면 포커스 이동이 아니라 들여쓰기가 입력되도록 처리
- 처음 열었을 때 간단한 샘플 코드가 미리 들어가 있게 한다

### 2. 실행 / 렌더링
- `▶ 실행` 버튼 클릭 시 코드를 `iframe.srcdoc`에 주입해 렌더
- `자동 실행` 체크박스: 켜져 있으면 타이핑이 멈춘 뒤 500ms 디바운스로 자동 갱신
- Ctrl+Enter(Mac은 Cmd+Enter) 단축키로도 실행
- **보안**: iframe에 `sandbox="allow-scripts"` 만 부여한다.
  `allow-same-origin`은 절대 함께 넣지 말 것 (부모 페이지 조작 위험)

### 3. 콘솔 출력 (중요)
sandbox iframe 내부의 출력을 부모 창에서 볼 수 있어야 한다.
- iframe에 주입되는 코드 **맨 앞에** 후킹 스크립트를 자동으로 덧붙인다
- `console.log / warn / error`를 가로채 `parent.postMessage`로 전달
- `window.onerror`와 `unhandledrejection`도 잡아서 전달
- 부모는 `message` 이벤트로 받아 콘솔 영역에 출력
- 에러는 빨간색, 경고는 노란색, 일반 로그는 기본색으로 구분
- 에러 발생 시 줄 번호도 함께 표시
- 실행할 때마다 콘솔은 초기화

### 4. 툴바 버튼
- ▶ 실행
- 🔄 초기화 (확인 창을 띄운 뒤 샘플 코드로 되돌림)
- 📋 코드 복사 (클립보드 복사 후 "복사됨!" 토스트 표시)
- 💾 HTML 저장 (입력한 코드를 .html 파일로 다운로드)
- 🪟 새 탭에서 보기 (미리보기만 전체 화면으로)
- 📱 미리보기 폭 전환: 전체 / 모바일(375px) 토글

### 5. 자동 저장
- 입력한 코드를 localStorage에 자동 저장
- 페이지를 다시 열면 마지막 코드를 복원
- **주의**: localStorage는 반드시 부모 창에서만 사용한다
  (sandbox iframe 내부에서는 접근이 차단됨)
